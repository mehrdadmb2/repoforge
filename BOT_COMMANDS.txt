start - Start RepoForge and show administrator status
help - Show the complete command guide
status - Check Worker, GitHub, KV and queue status
repos - List and choose an allowed repository
select - Choose repository and branch
current - Show the selected repository and branch
branches - Change the selected branch
upload - Show ZIP upload instructions
jobs - List recent deployment jobs
preview - Preview the latest deployment job
files - Review file-level Update, Keep and Delete actions
deploy - Prepare a deployment and continue in dashboard
cancel - Cancel an uploading or pending deployment job
backup - Create a manual Git backup
backups - List recent backups
restore - Restore a selected backup
history - Show recent commits
